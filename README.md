# Sales Data Analysis

## Project Overview
This project focuses on analyzing sales data to understand business performance and identify trends in sales and profitability.

## Objectives
- Analyze total sales and profit.
- Evaluate sales performance across regions and product categories.
- Identify trends and patterns in business data.
- Support data-driven decision-making.

## Tools & Technologies
- Microsoft Excel
- PivotTables
- Data Analysis

## Key Findings
- Total Sales: $2.29M
- Total Profit: $286.4K
- Profit Margin: 12.47%

## Skills Demonstrated
- Data Analysis
- Data Organization
- Business Insights
- Analytical Thinking
